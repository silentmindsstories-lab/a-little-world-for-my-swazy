# A Thousand Little Reasons — For Swazy ♡

## Run it in VS Code
1. Extract this folder somewhere easy to find.
2. Open VS Code.
3. Choose **File → Open Folder…** and select `swazy_fairytale_site`.
4. Open `index.html`.
5. If you have the **Live Server** extension, right-click `index.html` and choose **Open with Live Server**. Otherwise, double-click `index.html` in File Explorer to open it in your browser.

## Add “Die For You”
The website cannot include the copyrighted song file itself. If you have a copy you're allowed to use, rename it exactly to `die-for-you.mp3` and place it in this same folder beside `index.html`. Refresh the website, then press **Play music**. Browsers do not allow music to autoplay reliably, so Swazy will need to press the button.

If you don't have an audio file, remove or change the music option rather than downloading an unauthorized copy. The rest of the website works without music.

## Personalize the letter
Open `index.html` and search for `My dearest Swazy,`. You can edit the letter text directly. Keep the tags around paragraphs (`<p>...</p>`) so the layout remains intact.

## Files
- `index.html` — website structure and letter
- `style.css` — fairytale colors, stars, garden and animations
- `script.js` — interactive buttons, twinkling stars, fireflies and hearts
